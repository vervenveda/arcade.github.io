Quantum Orb Guide

Spin

Creates one coherent six-part constellation. The welcome preview does not alter today or lifetime counts.

Lock

Lock any component you want to preserve. Future spins reroll only the unlocked pieces.

Reroll

Each individual field can be rerolled without changing the rest of the constellation.

Seed Code

Every spin receives a deterministic code. Entering the same code through import reconstructs the same unlocked choices.

Daily Constellation

Uses the player’s local calendar day rather than UTC, so the daily seed changes at local midnight.

Writing Desk

Drafts autosave locally, carry a timer, and remain connected to the seed that inspired them.

Archive

Save favorites, pin important seeds, restore a constellation, reopen drafts, search, or remove individual items.

Privacy

No account, analytics, cloud service, external font, or network request is used.

# Privacy Notice

_Last updated: July 29, 2026_

## Overview

Arcade™ is a public, local-first browser arcade within the Verve N Veda network.

The Arcade landing page is designed to work without:

- user accounts;
- advertising;
- behavioral tracking;
- analytics;
- payment processing;
- remote profiles;
- server-side game saves;
- third-party runtime scripts.

## Information Stored in the Browser

The Arcade may use `localStorage` to remember preferences such as pinned cabinets.

The current pinned-cabinet key is:

```text
arcade_pinned_cabinets_v2
```

This information remains in the visitor's browser unless the visitor clears site data, uses private browsing, changes devices, or the browser removes stored data.

The project owner does not receive this localStorage information through the Arcade site.

## External Destinations

Some Arcade cards open public pages in other Verve N Veda repositories, including Bazaar Art and Aurora Sanctuary.

Those destinations may have their own privacy notices and browser-storage features. Visitors should review the notice provided by the destination they open.

## GitHub Pages Hosting

The public site is delivered through GitHub Pages. GitHub may process routine technical information needed to provide and protect its hosting service, such as network and request information, under GitHub's own policies.

Arcade™ does not add independent analytics or tracking to that hosting layer.

## Children and Families

Arcade™ includes games and learning activities suitable for a broad audience. The site is not designed to request a child's name, address, school, email address, account credentials, or other personal profile information.

Children should use external links with the guidance appropriate for their age and household.

## Sensitive Information

Do not enter confidential, medical, legal, financial, account, or identifying information into a game unless that game clearly explains why it is needed. Arcade games should ordinarily function without such information.

## Clearing Local Data

Visitors can remove Arcade preferences by:

- unpinning games within the Arcade;
- clearing site data in the browser;
- using a private browsing session;
- removing the stored key through browser developer tools.

## Changes to This Notice

This notice may be updated when the Arcade adds new storage, hosting, or public-interaction features. Material changes should be recorded in `CHANGELOG.md`.

Color Clash Guide

True Color

Hue and word always agree. Tap bubbles whose color matches the target.

Ink Focus

The word may conflict. Judge only the bubble’s visible hue and ignore its written label.

Word Focus

The bubble hue may conflict. Judge only the written color word.

Reaction Score

Fast correct responses earn more points. Five-hit streak bands increase the multiplier.

Lane Keys

Keys 1–6 strike the lowest visible bubble in the corresponding lane. Pointer and touch remain fully supported.

Focus Survival

The round ends immediately when Focus reaches zero. Correct catches restore a small amount.

Target Shift

The old field is cleared before the new target appears, so no bubble changes meaning while visible.

Keyboard

P pauses. Escape pauses. Space pauses or resumes when no setup control is focused.

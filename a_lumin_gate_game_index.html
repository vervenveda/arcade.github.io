Lumin Gate Guide

Visible Rune Logic

Rotating a sigil changes the rune shown at its center. The displayed rune—not an invisible hidden value—is what travels through every connected thread.

Exact Thread Count

Each receiver shows how many threads it needs. It is satisfied only when the count is exact and every incoming rune matches.

Select · 1

Tap a sigil to select it. The Gate Matrix provides the same selection controls for keyboard and screen-reader use.

Rotate · 2

Tap a sigil to rotate clockwise, or use Q and E for the selected sigil. Rotation snaps to one clear rune state.

Weave · 3

Select a sigil, then tap a receiver to add or remove that exact connection. Modifier keys are not required.

Move · 4

Drag sigils to organize the field. Moving does not change the puzzle solution.

Pause

P or Escape pauses the timer and aurora interaction. The game also pauses automatically when its browser tab is hidden.

Undo / Redo

Ctrl/Cmd+Z and Ctrl/Cmd+Y reverse rotation, weaving, movement, and tool actions.

Guaranteed Gates

Every gate is built from a complete source-to-rune solution before its starting rotations and noise threads are applied.

Challenge Codes

Codes contain a seed, depth, and checksum. Invalid or altered codes are rejected before a gate is loaded.

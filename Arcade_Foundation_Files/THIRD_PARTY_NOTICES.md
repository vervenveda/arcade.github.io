# Third-Party Notices

Arcade™ is intentionally designed to minimize external dependencies.

## Current Landing Page

The Arcade landing page uses:

- standard HTML;
- handcrafted CSS;
- vanilla JavaScript;
- system and locally available font fallbacks;
- Unicode symbols and emoji supplied by the visitor's operating system or browser.

The landing page does not require a remote JavaScript framework, analytics service, advertising network, remote font service, or runtime API.

## Browser and Platform Features

The project relies on standard browser features such as:

- `localStorage`;
- CSS Grid and Flexbox;
- media queries;
- reduced-motion preferences;
- standard form controls;
- the DOM event system.

These platform features are not bundled third-party libraries.

## Individual Games

Individual game files may contain adapted ideas, public-domain game traditions, open data, open-source snippets, fonts, icons, sounds, or other material with separate terms.

Before publishing or revising a game, record any such material below or add a game-specific notice.

## Maintenance Rule

When adding a third-party asset:

1. confirm that its license permits the intended use;
2. preserve required attribution;
3. record the exact source and license;
4. store a local copy of the license when required;
5. avoid assets with unclear ownership;
6. do not commit purchased font files or other restricted files unless the repository is authorized to contain them.
